# Basalt 开发入口与旧章节索引

开发机准备、仓库初始化与开发流程已统一到 [Harness 与 Loop 开发操作](DevelopmentLoop.md)。本文件保留旧路径和章节索引，避免已有技能、模块文档与外部链接失效；不维护第二份安装命令、US 依赖表或验收流程。

已有仓库从开发操作 §9 续跑；新开发机先看 §10；产品使用与部署见 [Operations.md](Operations.md)。现行版本、契约和门禁仍分别由技术方案、`go.mod` / CI、`docs/contracts/` 与 Makefile 定义。
