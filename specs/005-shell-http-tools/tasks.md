## Phase 3: User Story 1 - 出网取数：两件 HTTP 工具与逐跳判定（Priority: P1）🎯 MVP

**Goal**: `http_get` / `http_post` 两件工具共用一份逐跳循环（流程 B 逐块同构）——**每一跳发送前**过 `policy.Check`（scheme / host / 端口 / 域名只此一处判）、客户端不自行跟随重定向（`CheckRedirect` 返回 `ErrUseLastResponse`、`Transport.Proxy` 恒 nil）、五种状态码的重定向语义集中 `httpRequestSpec.next` 一处、跳数上限 5（初始不计，超限 `sandbox_denied`）、跨源不转发模型头、4xx/5xx 与 DNS/连接/TLS/读取失败归 `ExternalError`（先判 ctx 再包装）、出站 body 超 256 KiB → `invalid_input` 零发送；**端口冻结组合**（口径 15）在策略层一次落地
