# US-19 数据模型

领域对象、状态与合法意图组合见 [正式契约](../../docs/contracts/flow.md#1-领域对象状态与目录协议)，PG 记录关系见该契约第 3 节。IDs=text、时间=Unix ms、JSONB 含 format_version；同任务复合 FK、唯一幂等键、不可变版本、CAS 与 CHECK 约束都必须由真实 PG 测试验证。当前版本7，新增0008_flow.sql，不改前7版。

当前头指针／契约 FK 可延迟但事务提交时必须完整；关闭状态、转移、操作事实和预算同事务，外部调用不进事务。终态与关闭意图不清除 unknown、未知预算及恢复引用。
