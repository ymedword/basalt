# US-16A Data Model

## Forward Migration

追加 0006_observability.sql；运行期 SupportedSchemaVersion 从 5 到 6；0001–0005 与 schema.pg.sql 字节保持。所有时间 bigint Unix 毫秒 UTC，identity 使用 GENERATED BY DEFAULT AS IDENTITY。

- runs.request_id：可空 text，合法形状1–64字符，部分索引；历史 NULL不回填。
- llm_calls.recovered_at / tool_invocations.recovered_at：可空 bigint；恢复 pending→unknown 的同一 UPDATE 写入，不改变恢复业务语义。
- context_assembly_records.retrieval：可空 JSONB，字段为真实 top_k/candidate_k/budget_tokens/filtered_count/filtered_reason/index_generation；缺失键保留缺失。budget DROP NOT NULL，非chat写NULL；candidates每项新增Decision。

## OBS Owned Tables

- observability_export_items：item_id、source_kind/source_id/state_hash唯一键、signal、source_terminal_at、state、attempts、last_batch_id、next_attempt_at、lease_until、last_error_kind、created_at/updated_at/sent_at；指标派生快照最小脱敏payload内部持久化，不能重算冒充。
- observability_export_batches：batch_id、signal、record_unit、item_count/record_count、可空accepted_records/rejected_records、partial_success、warning_present/脱敏warning_text、outcome、http_status/error_kind/duration_ms、attempted_at。unknown尝试不能证明请求已发出。
- observability_export_scan：source_kind、coverage_kind、可空covered_from/covered_through、last_scan_started_at/last_scan_at/last_reconcile_at/updated_at；下界首次完整扫描固定，上界CAS单调推进。
- observability_cleanup_runs：cleanup_id/table_kind/window_start/window_end、覆盖上下界、确认要求、删除/跳过数、skip_reason/status/error_kind、开始/结束。删除与账本同事务；无逐条墓碑。
- observability_alert_states：rule_id/scope_key主键、state/since/last_eval_at/last_value/updated_at；只保留当前状态。
- observability_alert_transitions：identity id、rule_id/scope_key/from_state/to_state/value/occurred_at/evidence_ref；resolved仅转换。LoadStates同时从既有转换查询最近可评估状态/时刻，填入内部恢复元数据，重启后unknown不能遗忘此前firing；不新增表或对外JSON字段。

## Enumerations and Read Models

权威代码枚举、迁移后CHECK与API暴露枚举做集合对齐；未知旧枚举可读、写侧拒绝未知。时间线来源9种，导出扫描8种，指标快照另1种，SourceKind总集合10种；assembly不外发、metric_snapshot不进入时间线。

事实只投影ID、时间、状态、原因、允许计数/哈希，不读取消息content、工具参数结果、知识正文或operation detail_json。显示的“已装配”不证明模型使用；缺失、派生、未知分别保留。
