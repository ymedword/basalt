## User Scenarios & Testing *(mandatory)*

### User Story 1 - 管理认证闸门与必填配置 (Priority: P1)

运维准备把 Basalt 部署到内网服务器。开放 HTTP 管理面的命令在启动时要求显式配置管理认证：`token` 模式必须给出可解析的凭证，`local_trust` 模式只允许全部回环监听。任何受保护请求都必须先通过 Host / Origin 守卫与来源归属，再按模式认证；同一来源连续认证失败会被限速。公开面只剩健康检查、管理台静态壳与根路径重定向。既有全部 API（建会话、发消息、无状态调用、调度端点）从此都需要凭据。

**Why priority**: 这是整个模块的安全底座。没有它，把服务暴露到非回环网络就等于把带 `shell` 工具的 Agent 开放给任何人；它是后续所有管理能力的前置闸门，也是本模块对既有面唯一的破坏性变更。

**Independent Test**: 用四种配置启动：`token` 模式配有效环境变量凭证、`token` 模式缺凭证、`local_trust` 模式配非回环监听、未配置任何模式。前两种分别应正常运行与拒绝启动；后两种拒绝启动。再对运行中的实例发六类请求：缺凭据、错误凭据、错误认证方案、Host 不符、Origin 不符、公开路径无凭据。前五类按固定状态码拒绝，公开路径放行；第 10 次同来源失败返回限速状态码。

**Acceptance Scenarios**:

1. **Given** `http.admin_auth.mode=token` 且凭证来自环境变量占位符，**When** 启动 `serve`，**Then** 进程正常启动且访问日志不出现凭证原文。
2. **Given** `mode=token` 但凭证为明文、为空、或仍是未解析的 `${...}`，**When** 启动，**Then** 进程拒绝启动并以可读文案点名配置键。
3. **Given** `mode=local_trust` 且监听地址含非回环地址，**When** 启动，**Then** 拒绝启动；所有监听均为回环时启动成功。
4. **Given** 无凭据或凭据错误，**When** 请求任一非公开 API，**Then** 返回 401 且文案不区分"缺失"与"无效"；`local_trust` 下非直接回环对端返回 403。
5. **Given** 同一来源在 60 秒内连续失败，**When** 第 10 次尝试，**Then** 返回 429 并带 `Retry-After`；窗口过期后计数清零。
6. **Given** 直接对端不在可信代理范围，**When** 请求携带伪造转发头，**Then** 归属取直接对端，不采信转发头。

### User Story 2 - 运行资源账与运行观测 (Priority: P1)

审计员需要核对"这次运行到底用了什么"。每次运行在准入时固定 Provider、MCP 服务与技能发布版本，构造资源清单与哈希，并在同一事务内写入运行记录、清单与全部资源引用；运行终态在同一事务内释放引用。审计员在管理台看到运行列表与详情，详情展示准入清单；本能力之前产生的历史运行明确标为"未记录"，不补造。运行详情中的最终文本来自该次运行最近一条助手消息。运维可以取消一个跑飞的运行。

**Why priority**: 可核对性是企业 Agent OS 的核心差异点。没有资源账，"改了配置才知道当时用了什么"就是审计黑洞；取消能力则决定运维能否止血。

**Independent Test**: 发起一次运行并等其结束，检查运行记录、资源清单与资源引用三者凭运行标识互相关联；查历史库中本能力之前的运行，详情显示"未记录"且无清单行；对在跑运行发起取消，确认运行按取消信号自行收场，重复取消返回当前终态。

**Acceptance Scenarios**:

1. **Given** 一个启用中的 Agent 与可用资源，**When** 发起运行，**Then** 运行记录、资源清单与全部资源引用在同一事务内写入；任一写入失败整笔回滚，零运行、零引用。
2. **Given** 运行到达终态，**When** 终态写入，**Then** 同一事务内释放全部资源引用；终态写入失败时不覆盖既有终态。
3. **Given** 一个本能力之前产生的运行，**When** 查看详情，**Then** 返回 `legacy_unrecorded` 标记且不构造清单。
4. **Given** 正在运行的运行，**When** 调用取消，**Then** 只发取消信号并最多等待 30 秒，终态由运行自身写入；重复取消返回当前终态；未知运行返回 404。
5. **Given** 已结束的运行，**When** 再次取消，**Then** 返回终态且不产生第二次副作用。

### User Story 3 - Agent 生命周期准入 (Priority: P1)

运维停用一个 Agent 后，新运行必须被硬性拒绝且提示不可用，已在途的运行继续完成；重新启用后，HTTP、CLI 与定时入口都能重新运行。生命周期状态以工作区内的状态文件为唯一权威：文件缺失或损坏时拒绝新运行并点名原因，不静默当作可用。

**Why priority**: 停用如果只是界面文案或内存开关，重启、CLI、定时器任一入口都能绕过，安全承诺就不成立。它是管理面可信度的第二根支柱。

**Independent Test**: 启用一个 Agent 并跑一次；停用后再发起 HTTP / CLI / 定时三类运行，全部以固定不可用错误拒绝；在途运行继续完成；重新启用（带期望版本号）后三类入口恢复可运行；手改状态文件使校验和失效，确认拒绝新运行且错误点名生命周期。

**Acceptance Scenarios**:

1. **Given** Agent 状态为 `disabled`，**When** 发起运行，**Then** 返回 409 与固定不可用错误码，不产生运行记录。
2. **Given** 停用时仍有在途运行，**When** 运行继续，**Then** 不被取消并正常收尾。
3. **Given** 状态文件缺失或校验和不符，**When** 发起运行，**Then** 拒绝并点名生命周期错误；**不得**回落为启用。
4. **Given** 请求启用时的期望版本号与当前不一致，**When** 启用，**Then** 返回 409，状态不变。
5. **Given** 启用成功，**When** 再次通过 HTTP / CLI / 定时入口发起运行，**Then** 全部放行且行为一致。
6. **Given** 从 v1 数据库升级到 v2，**When** 基线完成并开放服务，**Then** 既有 Agent 的状态文件为 `disabled`、`generation=1`，新运行被拒绝直到显式启用；**不得**自动激活。

### User Story 4 - Agent 配置内容条件写 (Priority: P2)

运维在管理台编辑 `AGENT.md`：页面先读取内容并拿到强 ETag，保存时必须回传。若期间文件被别人改过，保存返回 412 且磁盘逐字节不变；刷新后重试成功。除整份替换外，还可以提交结构化补丁，只改指定字段，未改字段、正文、注释与行尾风格逐字保留；无法安全保留时明确拒绝，不静默丢注释。写入与热加载走同一道校验与发布闸门。

**Why priority**: "改文件即生效"必须可控。没有条件写，两个人同时编辑会静默覆盖；没有补丁保留规则，注释与格式会被工具吃掉。

**Independent Test**: 读取内容得到 ETag；用旧 ETag 保存确认 412 且文件哈希不变；刷新后保存成功并返回文件集合视图；提交一个只改某字段的补丁，确认未改字段、注释、正文逐字节保留；提交触碰正文或无法锚定的补丁，确认明确拒绝且零写入。

**Acceptance Scenarios**:

1. **Given** 当前内容 ETag，**When** 用匹配的 If-Match 整份替换，**Then** 写入成功并返回该 Agent 的文件集合视图。
2. **Given** 陈旧 ETag，**When** 保存，**Then** 返回 412，文件与快照均不变。
3. **Given** If-Match 缺失、弱比较或 `*`，**When** 保存，**Then** 返回 412，零写入。
4. **Given** 只改 frontmatter 字段的补丁，**When** 保存，**Then** 未改字段、注释、正文、行尾风格逐字节保留。
5. **Given** 补丁触碰正文或锚点不唯一，**When** 保存，**Then** 返回 `EDIT_UNSUPPORTED`，零写入。
6. **Given** 两个并发保存携带同一 ETag，**When** 同时提交，**Then** 恰好一个成功，另一个 412。

### User Story 5 - 配置热加载与边界 (Priority: P2)

运维直接修改 Agent 目录或技能目录下的文件：新运行使用新配置；手滑改坏时旧快照继续服务并留警告，不中断现有运行。对于必须重启才生效的配置（MCP 定义文件、沙箱白名单、Provider 段、HTTP 段），管理台与文档明确提示"需重启"，不得伪装生效。

**Why priority**: 热加载若无边界，运维会误以为改了 MCP 或白名单已经生效，导致"看起来改了、实际没变"的安全错觉。

**Independent Test**: 运行中修改 `AGENT.md` 并等防抖窗口，确认新运行使用新配置、在途运行不受影响；写入坏配置，确认旧条目保留且有警告；修改 MCP 定义文件，确认页面明确标"需重启"且新连接未建立。

**Acceptance Scenarios**:

1. **Given** 已建立的监听，**When** 原子替换 `AGENT.md`，**Then** 防抖后全量 rescan 并原子替换注册表，新运行使用新快照。
2. **Given** 写入解析失败的配置，**When** 防抖结束，**Then** 旧条目保留、记录警告、服务不中断。
3. **Given** 新建 Agent 子目录，**When** 目录出现，**Then** 被补进监听并参与 rescan。
4. **Given** 修改 MCP 定义文件或沙箱白名单，**When** 查看管理台，**Then** 显示"需重启"且不假装生效。
5. **Given** 控制目录，**When** 检查监听、浏览与文件工具白名单，**Then** 三面均不可见、不可写。

### User Story 6 - 只读资源面与系统概览 (Priority: P3)

运维在管理台查看技能、MCP 服务、模型连接、会话列表、Agent 记忆、沙箱白名单、通知渠道与类型，以及系统总览与进程采样。所有只读面不得泄露凭证：模型连接只回环境变量引用名，MCP 只回环境变量键名与可执行名，任何响应不出现绝对路径。采样在平台不支持或首次无基线时返回空值并列入不可用清单，不伪造读数。

**Why priority**: 观测是管理台的主要用途；但只读面若泄露凭证，管理台本身就成了新的风险点。

**Independent Test**: 逐个请求只读端点，检查响应中不出现凭证值、环境变量值或绝对路径；在不支持的平台请求采样，确认对应字段为空且列入不可用清单；两次采样在 5 秒内返回同一缓存结果。

**Acceptance Scenarios**:

1. **Given** 已发布资源，**When** 请求技能 / MCP / 模型连接列表，**Then** 返回发布视图且只含引用名。
2. **Given** 会话列表，**When** 用 Agent 或状态过滤，**Then** 按固定排序返回并正确标记 `active` / `archived`；非法状态返回 400。
3. **Given** Agent 记忆，**When** 读取，**Then** 返回 Agent 层内容；不存在时 404，读取失败 500，不回退全局层。
4. **Given** 不支持采样的平台，**When** 请求系统采样，**Then** 对应字段为 null 并列入不可用清单；响应不含磁盘与运行时长字段。

### User Story 7 - 内嵌管理台 (Priority: P3)

运维打开浏览器访问管理台：登录页输入 token（只在页面内存保存，关闭即失效），进入总览、Agent、运行、资源与操作五个区域。深链接可以直接刷新，浏览器后退有效，未知路径显示 404；模型文本以安全子集渲染，不执行脚本；认证过期时跳回登录并有明确提示；有未保存修改时离开会提示。管理台构建产物随源码提交并嵌入单二进制，运行时不从磁盘读取前端文件，也不加载任何外部 CDN。

**Why priority**: 管理台是交付形态的一半，但它依赖前六个故事的能力；没有安全渲染与内存凭据，管理台会引入新的 XSS / 凭证泄漏面。

**Independent Test**: 无 Node 环境下运行常规 Go 门禁与验收入口，确认不调用 Node；在浏览器中直接打开 `/console/runs/<id>` 深链接并刷新，确认页面正确渲染；输入包含脚本的模型文本，确认按文本显示；检查页面网络请求不含 CDN 外链。

**Acceptance Scenarios**:

1. **Given** 单二进制产物，**When** 请求 `/console/*`，**Then** 返回内嵌静态资源；请求未知深链接返回管理台壳并由前端渲染 404。
2. **Given** 未认证会话，**When** 打开非登录页面，**Then** 跳转登录并保留目标路径。
3. **Given** 包含 HTML 与脚本的模型文本，**When** 渲染，**Then** 只按固定标签渲染，脚本不执行、链接只允许 `http` / `https`。
4. **Given** 已构建产物与完整性清单，**When** 运行 Go 侧校验，**Then** 目录文件集合与清单集合一致且逐文件哈希相等。

### Edge Cases

- 管理认证配置存在但 token 环境变量未设置：启动失败，文案点名配置键，不打印变量值。
- 同一来源在第 10 次失败后继续尝试：持续 429，`Retry-After` 不小于窗口剩余时间；窗口外的旧失败不计入。
- `local_trust` 模式前面挂反向代理：请求直接对端是回环但携带转发头——仍按直接对端放行（本模式只看直接对端），文档明确该部署不安全；`token` 模式下转发头只用于归属。
- 状态文件在两次读取之间被替换：准入在 Agent 级读锁内重读，读到损坏或缺失即拒绝；不得以缓存值放行。
- 停用与启用并发：同一 Agent 级锁串行化，后到者按当前状态判定；期望版本号不符返回 409。
- 运行终态写入与取消同时发生：取消只发信号，终态由运行自身写入；重复取消返回当前终态，不覆盖。
- 资源发布失败：旧映射与旧版本继续服务在跑运行；新运行按旧发布指针准入；不得出现半发布。
- 技能发布版本目录缺失：准入失败并返回资源不可用，不得回落到工作副本。
- 启动时存在 pending 管理操作：只查证、不重做；无法确定结果标 `unknown` 并保留原行。
- 基线执行到一半进程崩溃：下次启动按可重入规则补齐，不重复建版本、不覆盖既有指针。
- 热加载监听失效（目录被删除后重建）：重建监听并全量 rescan；失败时保留旧注册表并告警。
- 前端产物缺失或哈希不一致：Go 侧测试失败；二进制构建因嵌入失败而无法完成，不得发布空壳页面。
- 数据库版本高于二进制支持版本：拒绝启动，提示升级二进制。
- 历史运行缺少资源清单：详情返回 `legacy_unrecorded`，不补造、不报错。

## Requirements *(mandatory)*

### Functional Requirements

#### 管理认证与请求保护

- **FR-001**: 开放 HTTP 管理面的命令**必须**在启动时校验 `http.admin_auth`：`mode` 缺失或取值不是 `token` / `local_trust`、`token` 模式缺少可解析凭证、凭证为明文 / 空值 / 未解析的 `${...}` 残留，一律拒绝启动并点名配置键；不开放 HTTP 管理面的命令**不得**要求该段。
- **FR-002**: 管理 token **必须**只接受 `${ENV_VAR}` 占位并经与 Provider 凭证相同的解析路径；解析结果**不得**出现在日志、错误文案或响应中。
- **FR-003**: `local_trust` **必须**要求全部监听地址为回环（`127.0.0.1` / `::1` / `localhost`），请求的直接对端为回环，且携带本地信任头 `X-Basalt-Local-Trust: 1`；携带任何转发头**必须**直接 403；不满足时启动失败或请求被拒。
- **FR-004**: 每个受保护请求的 `Host` **必须**与 `allowed_hosts` 之一逐字匹配（大小写不敏感、端口一致）；未显式配置时**必须**由监听地址派生；不匹配返回 403。
- **FR-005**: 浏览器来源的 `Origin` **必须**与 `allowed_origins` 之一完整匹配（`scheme://host[:port]`，无路径 / 查询 / userinfo）；`null` 拒绝；未配置时**必须**按监听地址派生。
- **FR-006**: 只有直接对端在 `trusted_proxies`（CIDR）内时，**才**解析 `X-Forwarded-For` 作为来源归因，可取**最右侧非可信**地址；其他情况一律以直接对端 IP 为来源。
- **FR-007**: 同一来源 IP 在 60 秒窗口内的**认证失败**必须累计——只统计 401 与 `local_trust` 的 403，Host / Origin 拒绝不计数；第 1–9 次正常返回并计数，第 10 次起（含第 10 次）在凭据校验前直接返回 429 `AUTH_RATE_LIMITED` 并带向上取整的 `Retry-After`；成功认证不重置窗口，计数只在窗口到期清零；计数为进程内、重启清零；401 文案**不得**区分"缺失"与"无效"。
- **FR-008**: 公开路由**必须**是闭集：仅 `GET /api/v1/health`、管理台静态壳（`GET /console/*`）与 `GET /` 重定向；其余全部 API（含既有建会话、发消息、无状态调用、调度端点）**必须**认证；新增路由**不得**默认公开。
- **FR-009**: 认证主体（actor）**必须**由中间件解析后作为显式参数传给处理函数，**不得**写入上下文；actor 字面量固定为四种：`token:<sha256(token) 前 16 位十六进制>`、`local_trust`、`cli:<user>`、`migration`。

#### 管理操作审计

- **FR-010**: 任何管理面高权限变更**必须**在改动目标之前成功写入一条 `pending` 状态的管理操作记录；预写失败 → 返回 500 `INTERNAL` 且**不得**执行变更；成功后**必须**回填终态。
- **FR-011**: 操作标识**必须**为 `op-<unix_millis>-<6 位小写字母数字>` 且全局唯一；US-11 的写动作固定为 `agent.content.update` / `agent.disable` / `agent.enable` / `system.baseline_v2`；只读观测与校验**不得**写操作记录。
- **FR-012**: 管理操作**不得**写运行账本、模型调用审计或工具调用审计，**不得**挂运行标识；运行审计也**不得**写管理操作。
- **FR-013**: 启动恢复**必须**在开放服务前扫描 `pending` 操作：按动作类型查证实际结果，在 `recovered_at` 记录查证时间并写 `verification`（`applied` / `not_applied` / `indeterminate`），回填终态或补偿；无法确定的标 `unknown` 并保留原行，**不得**盲目重做。

#### 资源基线与生命周期

- **FR-014**: 数据库迁移到新结构后、开放服务前，**必须**建立基线：Provider / MCP / 技能各建一个初始发布版本与发布指针、技能不可变快照与既有 Agent 的生命周期状态文件（初始 `state=disabled`、`generation=1`，**不得**悄悄激活；状态文件已存在但损坏 → 基线失败并拒绝启动）；基线**必须**先写 `pending` 操作；任一失败**必须**拒绝启动。
- **FR-015**: 基线**必须**可重入：重复启动幂等，部分完成按缺失项补齐；**不得**覆盖已有指针或重写已有版本。
- **FR-016**: 生命周期状态文件的路径、字段与字段顺序**必须**固定，内容带校验和，写入原子化；状态取值固定为 `active` / `disabled` / `archived`。
- **FR-017**: 运行准入**必须**在 Agent 级读锁内重读并校验状态文件；只有 `active` 放行；`disabled` / `archived` / 缺失 / 损坏**必须**拒绝新运行并返回 409 `AGENT_UNAVAILABLE`，**不得**静默当作可用。
- **FR-018**: 停用**必须**只拒绝新准入，**不得**取消在途运行；启用**必须**要求当前为 `disabled`、期望版本号匹配且资源校验通过，否则返回 409，状态不变。
- **FR-019**: 启停与准入**必须**共用同一 Agent 级读写锁，但准入读锁**只覆盖**"重读并校验状态文件"这一小段，判定后立即释放，**不得**跨越资源解析、`StartRun`、模型调用或工具执行；启停持写锁覆盖"校验期望 → 生成新状态 → 原子写 → 同步索引"。准入的线性化点是**状态放行判定**：停用写锁完成后开始的准入按新状态拒绝；在停用取得写锁之前已通过判定、尚未开账的请求**可以**继续完成 `StartRun`，其资源一致性由 `ResourceGate` 读租约保障——租约自资源解析起持有至 `StartRun` 成功，失败路径一并归还（见 FR-048）。**不得**声称"停用返回后不会再出现任何新 `StartRun`"——需要更强保证时必须重新设计临界区并给出测试。
- **FR-020**: 状态文件权威性**必须**在三类入口一致：HTTP、CLI、定时以及内部入口都经同一准入判定；**不得**出现第二份生命周期缓存。

#### 运行资源账与观测

- **FR-021**: 运行准入**必须**固定 Provider、MCP 服务与技能发布版本，构造资源清单与稳定哈希，并在**一个事务**内写入运行记录、资源清单与全部资源引用；任一失败整笔回滚。
- **FR-022**: 运行终态写入**必须**在同一事务内释放全部资源引用，且只更新仍为 `running` 的行；终态写入失败**不得**覆盖既有终态。
- **FR-023**: 没有资源清单的历史运行**必须**返回 `legacy_unrecorded` 标记与空清单；**不得**补造、**不得**报错。
- **FR-024**: 运行列表**必须**固定排序与窗口：`started_at` 倒序、`run_id` 倒序，`limit` 缺省 50、上限 200；只接受会话 / Agent / 状态三个过滤参数，未知参数忽略，非法状态（合法值 `running` / `completed` / `limit_reached` / `cancelled` / `failed`）返回 400。
- **FR-025**: 运行详情**必须**包含准入清单；最终文本**必须**取自该运行最近一条助手消息，没有则空串；持久清单形态与 HTTP 视图**必须**分离，视图可按契约省略生命周期状态。
- **FR-026**: 取消**必须**只对进程内在跑的运行发取消信号并最多等待 30 秒；终态由运行自身写入；响应固定为 200 + 当前运行视图（在跑取消后为 `cancelled`，已终态则原样返回）；未知运行 404；**不得**直接强写终态。
- **FR-027**: 运行准入失败分类**必须**固定：Agent 不存在 → 404；生命周期不可用 → 409 `AGENT_UNAVAILABLE`；资源不可用 → 500 固定文案；对应错误类型与文案逐字对齐契约。

#### 内容条件写

- **FR-028**: `GET /agents/{name}/content` **必须**返回强 ETag 与文件集合视图；ETag 格式固定为 `"sha256:<64 位小写十六进制>"`（含双引号），按原始 UTF-8 字节计算。
- **FR-029**: `PUT /agents/{name}/content` **必须**要求 `If-Match`：缺失、弱比较（`W/`）、`*` 或不匹配一律 412 `PRECONDITION_FAILED`，且磁盘零写入；并发保存只有恰好一个成功。
- **FR-030**: 内容写**必须**支持两种请求形态二选一：`content` 整份替换，或 `changes` 结构化补丁；补丁只改已知 frontmatter 字段，未改字段、正文、注释、行尾风格**必须**逐字保留；无法安全保留时返回 400 `EDIT_UNSUPPORTED` 且零写入。
- **FR-031**: 内容写**必须**走与热加载同一道校验与发布闸门：解码 → ETag 比较 → 生成候选 → 校验 → 原子写 → 校验通过后原子替换快照；任一步失败磁盘与快照均保持原样。
- **FR-032**: 内容写成功**必须**返回该 Agent 的文件集合视图；写操作**必须**先写 `agent.content.update` 的 `pending` 操作并回填终态。

#### 热加载与技能版本

- **FR-033**: 热加载**必须**只非递归监听已添加的目录：`agents/` 与每个 Agent 目录、`skills/` 与每个技能目录；新建目录**必须**补监听；`mcp_servers.yaml`、沙箱白名单与配置文件**不得**纳入监听。
- **FR-034**: 变更**必须**防抖后全量 rescan；校验通过才原子替换注册表；失败**必须**保留旧快照并记录 WARN；正在跑的运行**不得**受影响。
- **FR-035**: 需重启的变更（MCP 定义、沙箱域名 / 命令 / 解释器 / 路径白名单、Provider 段、HTTP 段）**必须**在管理台与文档中显式标"需重启"，**不得**伪装已生效。
- **FR-036**: 受保护控制目录**必须**三面排除：不在热加载监听、不在工作区浏览（US-12）、不在 Agent 文件工具白名单；文件工具对它一律拒绝。
- **FR-037**: 运行准入**必须**按每个绑定技能的当前发布版本与不可变目录读取；技能卡片与正文哈希**必须**按固定字节定义（整份 `SKILL.md`、卡片行、L2 正文、L3 资源）；运行中的运行**必须**永远读准入时固定的版本，**不得**回落工作副本。
- **FR-038**: 技能发布目录缺失或哈希不符**必须**按资源不可用拒绝准入，**不得**使用工作副本顶替。

#### 只读资源面与采样

- **FR-039**: 只读资源面**必须**覆盖技能、MCP 服务、模型连接、会话列表、Agent 记忆、沙箱白名单、通知渠道与通知类型；模型连接只回环境变量引用名，MCP 只回环境变量键名与可执行名；任何响应**不得**出现凭证值、环境变量值或绝对路径。
- **FR-040**: 会话列表**必须**固定按最近活跃时间倒序、`session_id` 次序，支持 Agent 与状态（`active` / `archived`）过滤；状态由归档时间派生。
- **FR-041**: 系统概览**必须**提供计数、数据库连通性与契约声明的版本 / 运行时长字段；系统采样**必须**提供进程 CPU、常驻内存与 goroutine，缓存 5 秒；平台不支持或首次无差值基线时字段为 `null` 并列入不可用清单；**系统采样**不得提供磁盘与运行时长字段。
- **FR-042**: 注册不变量**必须**先于观测：Provider 无发布指针、技能无发布版本、MCP 无生效版本或连接失败时，该 Agent **不得**注册；管理台看到的集合、准入集合与调度注册集合**必须**来自同一份不可变注册表快照。发布指针 / 版本查询失败**必须**失败关闭：启动拒绝，watcher 保留旧注册表。

#### 管理台

- **FR-043**: 管理台路由**必须**固定十二条（`/console/`、`/console/login`、`/console/agents`、`/console/agents/:name`、`/console/runs`、`/console/runs/:id`、`/console/resources/:kind`、`/console/operations`、`/console/library/tools`、`/console/library/memory`、`/console/settings/notifications`、`/console/settings/sandbox`），用 History API 自实现；深链接刷新与后退**必须**可用，未知路径渲染 404 视图。2026-10-22 UI-R2 选项 A 扩展仅为 FR-039 的既有只读能力及已有全局记忆端点增加独立入口；八条口径的历史审阅证据保留，不改后端端点、权限或写面。
- **FR-044**: 管理台**不得**加载任何第三方运行时资源（CDN 脚本 / 字体 / 样式），**不得**使用 `v-html` / `innerHTML` 渲染模型文本，**不得**引入路由库或 Markdown 库；渲染器只生成固定标签集，链接只允许 `http` / `https`。
- **FR-045**: 凭据**必须**只保存在页面内存，不写 `localStorage` / `sessionStorage` / Cookie；认证过期**必须**跳回登录并保留目标路径；有未保存修改时离开**必须**提示。
- **FR-046**: 前端构建产物**必须**随源码提交并嵌入单二进制；Go 层**必须**校验产物目录与完整性清单的文件集合一致且逐文件哈希相等；常规 Go 门禁与验收入口**不得**调用 Node；运行期**不得**从磁盘读前端文件。

#### 数据与一致性

- **FR-047**: 数据库**必须**升级到 v2：新增七张表（管理操作、资源版本、资源指针、运行资源清单、运行资源引用、生命周期索引、归档索引）与索引，建表幂等；已发布迁移**只追加、不得改写**；新库直接建到 v2，旧库前向迁移，库内版本高于二进制支持版本**必须**拒绝启动。
- **FR-048**: 进程内**必须**只有一道发布 / 准入共享闸门：准入持读锁，资源发布持写锁；**不得**出现第二套互斥或旁路。
- **FR-049**: 失败文案**必须**固定且脱敏：401 不区分缺失与无效；403 不解释命中规则；429 带 `Retry-After`；500 只回固定文案；任何失败文案**不得**包含内部路径、凭证、堆栈或原始外部响应体。
- **FR-050**: 管理台与只读面**必须**只展示契约声明的字段；**不得**擅自新增磁盘、运行时长或未声明字段。

### Key Entities *(include if feature involves data)*

- **管理操作**：一次管理面高权限变更的留痕，含操作标识、动作（`agent.content.update` / `agent.disable` / `agent.enable` / `system.baseline_v2`）、actor、目标 Agent、目标资源与版本、状态（`pending` / `success` / `failed` / `unknown`）、恢复查证（`applied` / `not_applied` / `indeterminate` 与查证时间）、开始与结束时刻；不挂运行标识。
- **资源版本**：Provider / MCP / 技能的一次不可变发布版本，含资源类型与名称、版本号、内容哈希、逻辑清单、落盘路径与发布操作标识。
- **资源指针**：每类资源的当前发布版本引用与已应用版本；发布失败保留旧指针。
- **运行资源清单**：一次运行准入时固定的资源集合与稳定哈希，含 Provider、MCP 列表与技能版本及文件哈希。
- **运行资源引用**：运行与具体资源版本之间的引用行，带释放时刻；终态同事务释放。
- **Agent 生命周期状态**：`.basalt/control/agents/<agent>.json` 的权威状态文件，含结构版本、Agent、状态、代次、更新时间与校验和。
- **生命周期索引**：数据库内的状态索引，由状态文件同步而来，用于查询与管理台展示；状态文件是权威，索引可重建。
- **归档索引**：Agent 归档目录的登记行（本 US 只读面准备，写面归 US-12）。
- **Agent 注册表快照**：一份不可变、原子替换的 Agent 集合视图，供准入、调度与管理台共同读取。
- **运行视图**：运行列表 / 详情的对外投影，含状态、最终文本与资源清单（历史运行标 `legacy_unrecorded`）。
- **系统采样**：进程 CPU、常驻内存、goroutine 与不可用字段清单；无磁盘与运行时长字段。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 非回环部署未配置有效管理认证时，启动失败率为 100%；配置缺失 / 非法 / 未解析凭证三种错误各给出可读点名，且不打印凭证值。
- **SC-002**: 全部非公开 API 在无凭据时被拒绝的比例为 100%；六类认证 / 守卫场景（缺失、错误、错误方案、Host 不符、Origin 不符、伪造转发头）行为与固定状态码逐项一致。
- **SC-003**: 同一来源 60 秒内第 10 次失败起 100% 返回 429 且带 `Retry-After`；窗口结束后不再限速。
- **SC-004**: 每次新运行产生恰好一份资源清单与对应引用；运行记录、清单、引用三者凭运行标识 100% 可互相追溯；事务故障注入下零半写。
- **SC-005**: 历史运行 100% 标为 `legacy_unrecorded` 且无补造清单；详情读取不因缺失清单报错。
- **SC-006**: 停用后新运行拒绝率为 100%（HTTP / CLI / 定时三入口），在途运行被取消的次数为 0；状态文件缺失或损坏时回落为可用的次数为 0。
- **SC-007**: 陈旧 ETag 保存 100% 返回 412 且磁盘零变化；并发保存中恰好一个成功；补丁保存对未改内容的逐字节保留率为 100%。
- **SC-008**: 热加载坏配置导致服务不可用或旧快照被替换的次数为 0；需重启的变更被标为已生效的次数为 0。
- **SC-009**: 只读面泄露凭证值、环境变量值或绝对路径的响应数为 0；采样在无基线时伪造读数的次数为 0。
- **SC-010**: 管理台在无 Node 环境的全量 Go 门禁下 100% 通过；产物目录与完整性清单不一致时门禁 100% 变红。
- **SC-011**: 本模块十七个专属自动检查全部通过，项目全量门禁（七目标）全绿；关键回归在实现被逆改时按预期变红。
- **SC-012**: 新增运行时依赖为 0 个（已批准的 fsnotify 除外）；发布二进制包含全部管理台资源且运行时不读外部前端文件。

## Out of Scope

以下项目在本模块明确不做，各有替代路径或归属阶段：

- 企业 SSO、RBAC、按人追责、多租户——扩展阶段。
- 调用方 API Key / QPS / 配额——第二阶段 US-16（拟）。
- TLS 终止与证书管理——反向代理承担，扩展阶段。
- 指标导出、日志聚合、告警、分布式节点监控——扩展阶段。
- Agent 创建 / 草稿 / 多文件提交 / 复制 / 归档 / 恢复——US-12。
- 模型连接 / MCP / 技能的写面与发布、资源删除、通知渠道 CRUD、工作区文件浏览——US-12。
- 技能工作副本外部修改自动发布——US-12 显式发布；启动基线只补缺失版本。
- `mcp_servers.yaml` / 沙箱白名单 / Provider 段 / HTTP 段热加载——明确提示"需重启"。
- 磁盘采样、管理台多语言 / 主题切换、页面内模型连接测试 / 技能导入 / 归档按钮——不实现、不显示。
- 浏览器端到端自动化——人工 Demo；前端只做单元测试。
- 审计查询的企业级检索 / 导出——核心阶段只提供固定窗口列表。

## Assumptions

- 硬依赖 US-9（HTTP 服务器、信封、错误映射、会话与调用端点、超时与优雅停机）与 US-10（调度器与定时页面入口）：本模块只在其上追加认证与观测面，既有 REST 路径与语义不变（认证是唯一破坏性变更）。
- 复用 US-1~US-8 已交付能力：SQLite 迁移、Agent 装载与校验、上下文快照、文件工具、审计两阶段写、Provider 映射、记忆读写、通知渠道；不重写这些能力。
- 契约文件（`openapi.yaml` / `run-and-errors.md` / `agent-md.md` / `schema.sql`）已在正式修订轮落盘，本模块只按契约实现、不改契约；契约与实现冲突时以技术方案与契约为准并停下报告。
- 新增运行时依赖只允许已批准的 fsnotify；Vue 3 + Vite 为已批准构建期依赖，不进 Go 模块、不进发布二进制；前端依赖版本在实施首日按包管理器源实测锁定。
- 进程由工作区实例锁保证单实例运行，因此发布 / 准入共享闸门只需进程内互斥，不需要分布式协调。
- 管理台只面向现代常青浏览器；不支持 IE、不做多语言、不做主题切换。
