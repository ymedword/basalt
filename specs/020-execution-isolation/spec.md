# Feature Specification: 执行隔离升级

**Feature Branch**: `020-execution-isolation`

**Created**: 2026-11-04

**Status**: 已审范围的实施规格

**Input**: US20 已审设计与用户持续开发授权；US19 已收口合入。

## User Scenarios & Testing

### User Story 1 - 部署者显式启用受控隔离 (Priority: P1)

部署者为受控工具选择隔离执行方式，保持既有本机部署兼容；配置与实际能力不匹配时拒绝接单。

**Why this priority**: 执行位置必须明确，错误配置不能让不可信任务落到宿主。

**Independent Test**: 旧配置仍可运行受控命令；绑定错误、镜像不可信和运行时缺失均拒绝启动。

**Acceptance Scenarios**:

1. **Given** 未启用隔离，**When** 调用原受控工具，**Then** 行为兼容；调用代码执行工具明确拒绝。
2. **Given** 已绑定隔离档，**When** 任何前置能力不满足，**Then** 拒绝启动且不降级。
3. **Given** 管理员允许经评审脚本，**When** 提交内联代码或越界脚本，**Then** 隔离档仍拒绝。

### User Story 2 - Agent 提交代码并取得可信产物 (Priority: P1)

Agent 在显式授权后执行单次生成代码，获得有界输出与经过校验的产物。

**Why this priority**: 提交、执行、回收与结果回填必须构成完整切片。

**Independent Test**: 正常执行可取回逐字一致的文件与哈希；无授权、越界输入、不合格产物均拒绝。

**Acceptance Scenarios**:

1. **Given** 未显式授权，**When** 请求代码执行，**Then** 不创建执行环境。
2. **Given** 授权及隔离可用，**When** 提交代码与合法输入，**Then** 返回退出状态、输出和已校验产物，只有一次调用审计。
3. **Given** 任务取消、超时或产物越界，**When** 收尾，**Then** 不发布半截产物，资源确认释放后才归还容量。

### User Story 3 - 运维恢复残留并查看真实状态 (Priority: P2)

运维可自检隔离前置、查看执行记录；重启清理残留，不重放结果未知的动作。

**Why this priority**: 崩溃恢复与容量核算决定持续运行的可用性和可审计性。

**Independent Test**: 崩溃种子经过恢复后无残留且容量恢复；清理失败保留占用；只读页面呈现实际档位。

**Acceptance Scenarios**:

1. **Given** 有账本的执行遗留，**When** 重启，**Then** 清理并保留未知结果；失败记录继续占容量。
2. **Given** 无账本孤儿或目录无法清理，**When** 启动，**Then** 拒绝接单。
3. **Given** 管理员查看概览和运行详情，**When** 隔离关闭、开启或有失败，**Then** 如实呈现，配置只能通过文件修改并重启。

### Edge Cases

- 创建响应丢失、运行时断连、取消时清理失败：不重试执行，不假定已清理。
- 任务自行创建不可访问目录、隐藏目录或符号链接：拒绝产物，仍完成有界清理。
- 两档同时准入或同时发布产物：共享容量，不重复计数、不超额发布。
- 一个任务耗尽共享输出区：允许其他任务失败，明确不保证任务间输出容量互不影响。
- 审计预写或运行账本预写失败：执行不得发出；终态写失败保留可恢复事实。

## Requirements

### Functional Requirements

- **FR-20-01**: 配置必须静态、严格、显式，保持默认本机兼容；非法档位、绑定、未知键及无效限额拒绝启动。
- **FR-20-02**: 接单前必须验证运行时、可信镜像、输出区及固定自检任务，失败拒绝启动。
- **FR-20-03**: 代码执行必须覆盖授权、输入暂存、有界执行、产物校验、结果回填及唯一调用审计；默认拒绝授权。
- **FR-20-04**: 受控命令可显式选择 OCI；解释器内联和越界脚本仍拒绝，不能退回本机。
- **FR-20-05**: 两档任务默认无网、无宿主凭证、只读根、非特权身份与最小权限；控制组证明负向验收有效。
- **FR-20-06**: CPU、内存、进程、临时空间、日志和产物必须有界；共享输出区提供总量硬限与单任务事后校验，不承诺逐任务输出硬配额。
- **FR-20-07**: 每次执行必须有明确生命周期、取消与超时收尾；确认全部资源释放后才记清理完成。
- **FR-20-08**: 启动必须清理账本遗留、标签孤儿和预写前目录；未知结果不重放，无法计入容量的残留必须阻断启动。
- **FR-20-09**: 产物只接受顶层普通文件，逐项验证路径、类型、数量、字节和哈希；完整发布或完整回滚。
- **FR-20-10**: 保持既有失败分类与出网拒绝语义，隔离细分原因使用独立闭集。
- **FR-20-11**: 管理面只读展示隔离档位、限额、检查结果与执行记录，不新增在线写入口。
- **FR-20-12**: 必须在授权 Linux 环境实际验证两档，缺环境或跳过不能记为通过。
- **FR-20-13**: 保持外部工具服务既有信任边界，不声称其已被本次隔离覆盖。
- **FR-20-14**: 两档共享准入，活跃与恢复残留不重复计数；清理失败占容量，恢复成功归还容量。
- **FR-20-15**: 镜像必须经过可信发布记录验签、批准内容标识匹配及实际镜像核对；不在运行期下载或接受任意自供镜像。

### Key Entities

- **执行档**：固定的运行时、镜像与资源限制，通过显式工具绑定选择。
- **执行记录**：与一次调用审计一对一的生命周期和清理事实，不替代审计结论。
- **产物**：受控发布的普通文件及其相对路径、字节数和内容哈希。
- **实例容量**：当前活跃执行与恢复残留占用的共同上限。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 15 条功能需求的必验项全部通过，两个执行档均具备真实运行证据，零必验跳过。
- **SC-002**: 一次调用只有一条审计记录；拒绝路径零执行；未知执行零自动重放。
- **SC-003**: 成功产物内容与哈希逐字一致；取消及被拒产物零发布；确认清理完成后残留数为零。
- **SC-004**: 同时持有 N 个执行时第 N+1 个被拒，释放一个后可再执行；并发发布不突破实例上限。
- **SC-005**: 安全、并发、审计及恢复关键反例能够检测相应保护被移除；既有回归和全量门禁通过。

## Assumptions

- 单实例工作区与独占输出挂载；部署者维护运行时和可信发布镜像。
- v1 只支持单次 shell 代码，任务内完全无网；不提供多语言、交互终端、在线配置、全工具自动隔离或第二套调度器。
- 不交付 microVM、MCP 全面隔离、多节点或正式 Compose/K8s 任务隔离编排。
- WSL Linux 属用户授权验收环境；不据此宣称 Windows/macOS 原生同等隔离。
- 不新增 Go 依赖，不调用真实模型、不操作生产实例。
