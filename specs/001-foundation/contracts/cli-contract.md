# 契约：命令行面（本 feature 交付部分）

**Feature**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md) | **Date**: 2026-10-15

本文件记录 US-1 交付的命令行面契约（两条命令 + 一个全局选项）。它**不新增**任何对外概念——全部取自 [docs/us/us1-foundation.md](../../../docs/us/us1-foundation.md) §2.3 流程 A / D 与 §3.1；命令全集与其余条目以 [docs/TechnicalSolution.md](../../../docs/TechnicalSolution.md) §8.7 为准。

## 命令面

| 命令 / 选项 | 语义 | 依据 |
| --- | --- | --- |
| `basalt init` | 幂等生成工作区骨架 + 引导建库（缺库创建；已存在库零写） | 流程 A；约束 8 |
| `basalt status` | 三节只读诊断报告（工作区 / 配置 / 存储），逐节尽力、节内失败不阻断后续节 | 流程 D |
| `basalt --version` | 输出包含**构建期注入**的版本标识 | 技术方案 §10.2；`TestEntryRun_VersionFlag` |
| `basalt help` / `basalt completion` | cobra 内建（框架自带，非本 feature 新增面） | cobra 默认行为 |

其余 10 条命令（chat / profile / serve / gateway / provider list / …）归对应 US。

## 退出码

| 码 | 语义 |
| --- | --- |
| 0 | 成功（含 `status` 三节全通过、`init` 二跑 Kept） |
| 1 | 失败——**具体原因由文案区分**，不分档非零 |

退出码唯一出口是 `app.Run`（流程 A 伪代码）。

## `basalt init` 输出契约

- **创建 / 保留清单**：向用户报告本次会话实际创建（`Created`）与已存在跳过（`Kept`）的成员；二跑时 `Created` 为空——这就是幂等的可读证据。
- **失败路径**：任一步失败 → ERROR 日志 + 可读文案 + 退出码 1。
- **不生成**实例配置 `basalt.yaml`（仓库只带 `basalt.yaml.example`）。
- **不取**实例锁、**不做**恢复、**不触碰**锁文件。

## `basalt status` 输出契约

**唯一工作区路径** = 当前工作目录的 `.basalt/`（不从配置取——三节必须出自同一路径）。

| 节 | 内容 | 失败判定 |
| --- | --- | --- |
| 1 工作区 | 目录 / 文件清点；未初始化 → 报「工作区未初始化 + 建议先跑 basalt init」 | 未初始化**计失败** |
| 2 配置 | 读当前目录的 `basalt.yaml` | **缺失 → 报「未发现配置（路径明示）」不计失败**；存在但无效 → 点名路径与键，计失败 |
| 3 存储 | 只读校验打开 `.basalt/basalt.db` | 库缺失 → 报「库未就绪 → 先 basalt init」；过高 → 报「请升级二进制」；旧版本 → 报「库版本 vN 旧于二进制 vM，需由重命令升级」；损坏 → 报「版本表存在但无版本行」——四态均计失败；就绪 → 报版本 + 表清点 |

**汇总**：三节全通过 → 退出码 0；任一节失败 → 退出码 1。

**红线**：三节输出（logger 缓冲 + 标准输出 + 标准错误**三路**）**不得**出现凭证明文值；`status` **只校验、不迁移**、不写库、不取锁、不恢复、不触碰锁文件。

## 环境契约

- 工作区路径由**当前工作目录**决定（`Deps.WorkDir` 注入，测试免 `chdir`）。
- 依赖环境变量只在 `${VAR}` 占位处取用；未解析残留一律拒绝并点名。
