# 合成演示采购需求 · 第 01 章 范围与部署

项目 SYN-AI-2026，版本 1。不是现实招标，不存在真实采购方。条款编号是来源锚点。

## R01

采购单节点自托管企业 Agent 平台；第一期不采购多租户 SaaS。

## R02

平台应支持多个业务 Agent 分别配置，复用公共模型、工具、渠道与记忆。

## R03

服务程序以单 Go 二进制交付；外部数据库单独部署，不能把单二进制解释为无数据库。

## R04

本期目标操作系统为 Windows amd64 和 Linux amd64；另外架构的支持须单独举证。

## R05

允许容器单实例交付；不得承诺已有跨机高可用、滚动升级或 Kubernetes 多副本能力。

## R06

材料必须固定产品版本；开发中的工作流功能须单列候选能力，不计入已交付基线。
