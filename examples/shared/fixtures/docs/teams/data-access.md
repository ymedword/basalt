# 数据访问与权限申请

> 本文件是 Basalt 的示例夹具：内容为虚构，不含真实人员、账号或凭据。
> This is a fictional fixture for the Basalt examples; it contains no real people, accounts or credentials.

## 数据分级与默认授权

数据分级口径见「信息安全基线」。默认授权只覆盖「内部」级别；「受限」及以上必须单独申请，并按字段列明用途。

| 级别 | 默认授权 | 申请要求 |
| --- | --- | --- |
| 公开 | 无限制 | — |
| 内部 | 团队成员 | 无需申请 |
| 受限 | 无 | 说明用途、字段清单、保留期限 |
| 机密 | 无 | 用途 + 期限 + 脱敏方案，两级审批 |

## 申请流程

1. 在工单系统选择「数据访问」模板，填写数据集、字段、用途与保留期限。
2. 直属主管审批用途，数据负责团队审批字段范围。
3. 通过后由平台管理员开通，授权期限默认 30 天，到期自动回收。
4. 需要延期的，重新提交申请；不允许对同一用途反复续期而不复核字段。

## 分析岗的常见约定

- 拉取「受限」数据后，结论只保留聚合结果；明细在分析结束后的 7 天内删除。
- 对外分享的图表不得包含可识别到个人的维度，小样本（少于 10 人）不单独出数。
- 需要长期看板的，申请固定的聚合视图，不要申请明细。

## 违规处理

未按申请范围使用数据、私下转存或转发，一经发现收回全部数据权限，并按公司制度处理。误操作（例如误查到超出范围的字段）应立即停止并主动上报，不追究责任。
