# 员工手册（示例节选）

> 本文件是 Basalt 的示例夹具：内容为虚构，不含真实人员、账号或凭据。
> This is a fictional fixture for the Basalt examples; it contains no real people, accounts or credentials.

## 入职第一周

| 事项 | 责任方 | 期限 |
| --- | --- | --- |
| 领取设备并登记资产编号 | 行政 | 入职当日 |
| 开通研发平台账号 | IT | 入职当日 |
| 完成信息安全基线学习 | 新同事本人 | 第 3 个工作日 |
| 与直属主管确认试用期目标 | 双方 | 第 5 个工作日 |

未在期限内完成的，由行政在周会通报，不涉及个人考核记录。

## 考勤与请假

1. 标准工作时间为每周一至周五，核心协作时段以团队约定为准。
2. 请假以半天为最小单位，需在系统中提前提交；病假可事后补提，须附说明。
3. 连续请假超过三个工作日，需要直属主管与部门负责人两级确认。

## 报销流程

1. 在费用系统新建单据，选择正确的费用科目。
2. 上传发票原件照片；金额超过团队日餐标的需要附事由说明。
3. 审批顺序为直属主管 → 部门负责人 → 财务复核。
4. 审批通过后的次月统一打款，到账日以财务公告为准。

## 试用期与转正

试用期为三个月。转正材料由本人提交，内容包括：试用期目标完成情况、参与的项目、以及一段对岗位的自我评估。评估结论只用于岗位安排，不进入公开记录。

## 遇到问题找谁

- 账号、设备、网络：IT 服务台
- 薪酬、假期、报销：人力资源
- 信息安全事件：按「信息安全基线」的流程上报，不要先在群里讨论
