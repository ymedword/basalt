# 信息安全基线

> 本文件是 Basalt 的示例夹具：内容为虚构，不含真实人员、账号或凭据。
> This is a fictional fixture for the Basalt examples; it contains no real people, accounts or credentials.

## 适用范围

本文适用于所有使用公司设备或公司账号的同事，包括实习与外包人员。第三方协作方按合同约定执行，由对接人负责传达。

## 账号

1. 一人一账号，不得共享。需要他人代为操作时，使用授权委托流程，不要出借密码。
2. 所有接入单点登录的系统必须开启第二因素认证。
3. 密码由密码管理器生成，长度不少于 16 位；同一个密码不得用于两个系统。
4. 离岗、转岗或项目结束后 3 个工作日内，由主管发起权限复核。

## 设备

1. 笔记本必须开启磁盘加密与自动锁屏（闲置 5 分钟）。
2. 不在个人设备上保存生产数据；确需离线处理的，先向信息安全申请。
3. 设备丢失后 1 小时内上报，IT 将远程擦除并冻结相关账号。

## 数据分级

| 级别 | 示例 | 存放要求 |
| --- | --- | --- |
| 公开 | 官网文案、已发布产品手册 | 无额外要求 |
| 内部 | 会议纪要、排期、内部流程 | 仅公司协作文档 |
| 受限 | 客户合同、个人信息、密钥 | 加密存储，按最小必要授权 |
| 机密 | 生产凭据、未发布财报 | 不进文档系统，走专用保管流程 |

## 事件上报

发现疑似泄露、钓鱼邮件或异常登录时：

1. 立即停止操作，保留现场（截图、邮件原文），**不要**转发给更多同事。
2. 通过信息安全值班渠道上报，写清时间、涉及系统、已做的处置。
3. 由信息安全判定是否需要隔离设备、轮换凭据；处置结论反馈给上报人和其主管。

诚实上报不会被视为违纪；隐瞒不报才会。
