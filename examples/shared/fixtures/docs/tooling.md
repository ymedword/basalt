# 研发工具与账号开通

> 本文件是 Basalt 的示例夹具：内容为虚构，不含真实人员、账号或凭据。
> This is a fictional fixture for the Basalt examples; it contains no real people, accounts or credentials.

## 开通方式

账号开通统一走工单系统，选择「研发环境」模板。申请单需填写：岗位、所属团队、需要访问的系统清单。审批人为直属主管，超过五个系统的申请追加部门负责人审批。

## 系统清单

| 系统 | 用途 | 默认权限 |
| --- | --- | --- |
| 代码托管 | 源码与评审 | 所属团队仓库只读 + 个人分支可写 |
| 持续集成 | 流水线日志 | 只读 |
| 日志平台 | 查询线上日志 | 只读，个人默认保留 7 天 |
| 指标看板 | 服务指标 | 只读 |
| 工单系统 | 需求与缺陷 | 提交与评论 |

需要写权限（合并主干、改流水线、改告警规则）的，另行申请，逐条写明范围。

## 本地环境

1. 开发机使用公司镜像，镜像已内置统一的工具链版本。
2. 依赖从内部镜像源拉取；直连外网源在办公网通常不可达，遇到超时先查镜像配置，不要反复重试。
3. 本地调试用的凭据放在个人加密目录，**不要**写进代码、脚本或提交记录。

## 常见问题

- **流水线卡在拉取阶段**：多为网络或镜像配置问题，先在工单系统搜索同类单再新建。
- **日志平台查不到个人服务的日志**：确认服务已登记到指标看板，未登记的服务不采集日志。
- **需要临时更高权限**：用「临时授权」模板，写明用途与到期时间，最长 5 个工作日。
