# web-watch —— 每日网页观察模板

抓取指定页面（静态页走 `http_get`，前端渲染页走 Playwright 浏览器快照），按固定
归一化规则与上次快照对比，报告变更行。口径写在 `AGENT.md`（本模板没有技能），
**无凭据、无脚本**。

档位：A*（浏览器待就绪）

## 领域

运维 / 市场——盯住状态页与变更日志这类「每天看一遍、变了要第一时间知道」的页面。

## 能力

- 两个观察页：静态页 `http_get`，动态页 Playwright 浏览器快照；
- 两条归一化规则（去行尾空白、丢空行）后按行做多重集合比对；
- 报告新增 / 删去行原文（各最多 10 行），并区分「有变更 / 无变化 / 不可用」；
- 任一页抓取失败时保留旧快照，下一轮重读同一段；
- 浏览器未就绪时动态页记「不可用」，**不**用静态抓取顶替。

## 工具与域名

| 项 | 值 |
| --- | --- |
| 内置 `tools:` 声明 | `http_get`、`read_file`、`write_file` |
| MCP 工具名 | `browser_navigate`、`browser_snapshot`（**候选**，以 Playwright server 实际 `tools/list` 为准，未实测） |
| `mcp_servers:` 声明 | `playwright`（stdio） |
| 出网域名 | `status.example.com`、`docs.example.org`（**占位**，导入时换成你自己的页面） |
| 内置域名白名单 | **无**——`http_get` 本身不带域名清单 |

**出网边界**：两件事分开看——

- 内置 `http_get` 受 Basalt 域名白名单约束：导入后必须在管理台「执行环境」把真实
  域名加进白名单，否则静态页每次都是 `sandbox_denied`；
- Playwright MCP 是本地 stdio 进程，它自己去打开页面，**不受** Basalt 白名单约束
  ——谁能被浏览完全由页表与浏览器决定，这是 A\* 档要人工确认的边界。

**playwright 配置要点**（`mcp_servers.yaml` 里一条，命令以你本机实际入口为准）：

```yaml
playwright:
  transport: stdio
  command: node
  args:
    - "<Playwright MCP 入口绝对路径>"
```

浏览器二进制、Node 版本与包入口三者缺一不可。

## 凭据

无。模板里不出现任何 `${...}` 占位；若你的观察页需要登录，本模板不适用
（`http_get` 不带登录态，浏览器侧也不保存会话）。

## 已知限制

- 归一化只有两条规则：页面里的实时刷新内容（倒计时、秒级时间戳）会让它**每次都
  报变更**；要抑制得更细就得加规则，而加规则就是改判据；
- 行序变化算「删去 + 新增」：页面重排会被报成变更，这是有意选择；
- 只比文本，不比截图、不比样式、不比链接状态码；
- 静态页与动态页的取法写死在 `AGENT.md` 第一张表里：换页面要改表并重跑夹具；
- Playwright 的包名、版本与浏览器二进制路径都在本仓库**未核实**，首次接入请以实际
  `tools/list` 为准；
- 需要登录态的页面不在本模板范围；
- 本 Agent 声明了 MCP server：`playwright` 没配好或连不上时，**整只 Agent 不注册**
  （加载期校验第 6 条，WARN `mcp server skipped: playwright`）——这也是它停在 A\*
  档的直接原因：浏览器没就绪，它连装载都过不了。

## 夹具与期望结果

`fixtures/pages.json` 提供两页的录制文本与上一轮快照（已归一化的行数组）。复跑时
用 `pages[]` 代替抓取、`previous_snapshot` 代替 `snapshot.json`，期望：

| 页面 | 本轮状态 | 结论 | 依据 |
| --- | --- | --- | --- |
| 服务状态页 | 抓取成功 | 无变化 | 归一化后正文含空行、去空行后与快照 5 行完全一致 |
| 文档变更日志 | 抓取成功 | 有变更 | 新增 2 行、删去 1 行 |

变更明细（照抄原文）：

- 新增：`- 2026-10-22 控制台筛选修复`、`- 2026-10-25 补充示例`
- 删去：`- 2026-10-21 修复控制台筛选`

首跑复跑（清掉快照）应为：两页都「无变更」但报告写明「首跑，只记快照」，并且不许
把快照里的旧内容当成变更——这条用于人工核对首跑语义。

## 通知路径

基线 `notify_mode: none`（零通知）。要每天推送：管理台把 `notify_mode` 改成
`allowlist` 并勾选渠道，再给 `daily-web-watch` 配 `deliver_to`；由系统在 Run 成功后
发送，模型不调用 `notify`、失败不自动补发。

## 生效方式

复制目录后：`mcp_servers.yaml` 加 `playwright` 条目并确认浏览器能起，把真实页面
域名加进白名单（静态页才需要），绑定模型连接，重启 Basalt（或走既有受控发布流程）。
`mcp_servers.yaml` 与 `AGENT.md` 的变更都要重启后生效。
