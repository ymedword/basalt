# 信息安全基线（示例节选）

> 本文件是 Basalt 模板的示例夹具：内容为虚构，不含真实策略编号、密钥或人员信息。

## 三条硬线

1. **凭证不入库**：密码、密钥、令牌一律写进环境变量占位，不进代码、不进文档、不进工单描述。
2. **数据只走批准的出口**：把数据发到外部服务之前，先确认该服务在批准清单里。
3. **最小权限**：只申请当前任务需要的权限；任务结束后主动回收。

## 账号与设备

- 所有生产系统账号必须开启二次验证，且与个人账号分离；
- 设备离开视线时锁屏；不再使用的设备交回行政注销；
- 借用他人账号属于严重违规，没有例外。

## 可疑情况怎么报

| 情形 | 立即动作 | 上报对象 |
| --- | --- | --- |
| 收到可疑邮件 / 链接 | 不点击、不转发附件 | 信息安全值班 |
| 怀疑凭据泄露 | 先轮换该凭据，再上报 | 信息安全值班 + 直属主管 |
| 设备丢失 | 远程锁定，随后上报 | 行政 + 信息安全值班 |

## 确认方式

读完后在协作平台对应条目下回复「已读」并注明日期。第 3 个工作日未确认的，行政会在周会提醒。
