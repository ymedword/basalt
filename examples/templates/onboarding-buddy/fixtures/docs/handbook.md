# 入职手册（示例节选）

> 本文件是 Basalt 模板的示例夹具：内容为虚构，不含真实人员、账号或凭据。
> This is a fictional fixture for the Basalt template; it contains no real people, accounts or credentials.

## 第一周要办的事

| 事项 | 责任方 | 期限 |
| --- | --- | --- |
| 领取设备并登记资产编号 | 行政 | 入职当日 |
| 开通协作平台账号 | IT | 入职当日 |
| 读完《信息安全基线》并签确认 | 新同事本人 | 第 3 个工作日 |
| 与直属主管对齐试用期目标 | 双方 | 第 5 个工作日 |

未在期限内完成的，由行政在周会提醒，不涉及考核记录。

## 考勤

1. 标准工作时间为每周一至周五；核心协作时段以团队约定为准。
2. 请假以半天为最小单位，提前在系统提交；病假可事后补提，需附说明。
3. 连续远程超过三个工作日的，需团队负责人在系统里确认。

## 找谁

| 问题类型 | 找谁 | 渠道 |
| --- | --- | --- |
| 设备、账号、权限 | IT 服务台 | 工单系统 |
| 合同、薪资、社保 | 人事 | 人事邮箱 |
| 业务数据怎么取 | 数据平台组 | 数据申请流程（见子目录） |

## 第二周开始

- 参加所在团队的周会，了解当前目标；
- 由导师安排一次「跟着做一遍」的实操；
- 阅读团队自己的约定文档（不在本手册里维护）。
