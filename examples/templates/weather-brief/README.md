# weather-brief —— 每日天气简报模板

一份可复制的最小模板：用内置 `http_get` 调 open-meteo，按记忆里的偏好判断
带伞 / 防暑 / 通风，写出固定格式的天气简报。**无凭据、无 MCP、无脚本**，适合作为
「第一次把一个 Agent 放进 Basalt」的起点。

档位：A（全量）

## 领域

个人行政——每天固定时间给出一条可以照着穿衣、带伞的天气结论。

## 能力

- 按日读未来三天：最高温、最低温、日降水量；
- 偏好（城市 / 带伞阈值 / 防暑阈值）读自记忆，缺省值写进 `AGENT.md`；
- 规则判断：带伞、防暑、注意温差、通风，四选多；
- 固定格式简报 `weather-brief.md`；取数失败只写失败段，不编造天气。

## 工具与域名

| 项 | 值 |
| --- | --- |
| `tools:` 声明 | `http_get`、`read_file`、`write_file`、`save_memory`、`recall_memory` |
| MCP | 无（`mcp_servers: []`） |
| 出网域名 | `api.open-meteo.com`（HTTPS 443） |
| 内置域名白名单 | **无**——`http_get` 本身不带域名清单 |

**出网边界**：`http_get` 受实例的域名白名单约束（管理台「执行环境」→
`network_domain_policy`，`basalt.yaml` 的 `http.allowed_domains` 只是首次种子）。
导入后**必须**把 `api.open-meteo.com` 加进去，否则每次运行都是 `sandbox_denied`。
白名单不因导入模板自动放宽。

## 文件范围

| 路径 | 读 / 写 |
| --- | --- |
| `weather-brief.md`（Agent 根目录） | 写（整文件覆盖） |
| `fixtures/city.json` | 只读（仅离线复跑用） |
| 记忆 | 读偏好、写偏好（偏好变化才写） |

## 凭据

无。open-meteo 的免费端点不需要 key；模板里不出现任何 `${...}` 占位。

## 依赖

| 依赖 | 说明 |
| --- | --- |
| Basalt 实例 | 提供 `http_get`、文件工具、记忆工具与调度 |
| 模型连接 | `provider.name: local-model` 是占位，导入后在管理台绑定自己的模型连接 |
| 网络 | 能访问 `api.open-meteo.com` |

## 档位

**档位：A（全量）**——完整 Agent 目录 + 夹具 + 固定期望结果 + 本 README；可装载；

## 证据状态

| 证据 | 状态 |
| --- | --- |
| 可装载、工具可解析 | 仓内 `TestTemplates_LoadAndTools` 覆盖（e2e tag） |
| 夹具复跑（规则与期望结果） | 仓内夹具 + 人工按 `AGENT.md`「夹具复跑」走一遍 |

「连接成功」不算业务可用；真实实连与真实模型 Run 都要在你自己的实例上另取证。

## 已知限制

- 只支持 open-meteo 的 `forecast` 端点，不含空气质量 / 紫外线 / 预警；
- 城市以经纬度写在 URL 里，换城市要改 `AGENT.md` 第 2 步的两组坐标（或让记忆覆盖，
  记忆只覆盖阈值与城市名，不覆盖坐标）；
- 三天窗口写死 `forecast_days=3`，改窗口同时要改简报模板的表格说明；
- 规则是阈值判断，不做「体感温度」等推导。

## 夹具与期望结果

`fixtures/city.json` 的 `forecast.daily` 三天数据（缺省偏好：带伞阈值 0.5 mm、
防暑阈值 32 °C）：

| 日期 | 最高 | 最低 | 降水 | 期望提示 | 依据 |
| --- | --- | --- | --- | --- | --- |
| 2026-10-25 | 24.1 ℃ | 18.3 ℃ | 0.0 mm | 通风 | 三条阈值都不命中 |
| 2026-10-26 | 27.6 ℃ | 20.4 ℃ | 6.4 mm | 带伞 | 降水 6.4 ≥ 0.5 |
| 2026-10-27 | 33.2 ℃ | 26.8 ℃ | 0.2 mm | 防暑 | 最高 33.2 ≥ 32 |

结论行应为「最需要提醒的是 2026-10-26 带伞与 2026-10-27 防暑」一类不含新事实的
复述；**不得**出现三天之外的日期或表外指标。

## 通知路径

基线 `notify_mode: none`（零通知）。要每日自动推送：管理台把本 Agent 的
`notify_mode` 改成 `allowlist` 并勾选渠道（保存时才会写入 `notify` 工具），再给
`daily-weather-brief` 配 `deliver_to`；那一轮由**系统**在 Run 成功后发送，模型不
调用 `notify`、失败不自动补发。

## 生效方式

`AGENT.md` 与模板目录由工作区加载；改完文件后**重启 Basalt**（或按既有受控发布
流程）让新正文生效。域名白名单在管理台保存即生效，不需要重启。
